# Skillfleet example

This harmless example exists to demonstrate the portable skill layout. It does
not change files, call external services, or make decisions on the user's
behalf.

When explicitly asked to inspect the example, report:

1. The skill directory contains `SKILL.md`.
2. Its frontmatter name matches the directory name.
3. No supporting scripts are required for this example.
